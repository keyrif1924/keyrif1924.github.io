Movie Webpage Project

Context

For this project, I had to create a movie webpage using HTML and CC. We were given the task to either choose action, horror, comedy, and other choices. This project allowed us to practice our coding skills and use different HTML and CSS concepts. The title of our movie was called, "The Culling of the Johns", and it included a homepage and several other pages for the movies.

Content

For this project, we created a movie themed website about a group of characters entering John province to compete and face different challenges. John Kaisen teams up with John Rabbit to fight the powerful John Rod, but their battle takes an unexpected turn when John Curse appears. The story is divided into five parts, each with its own webpage. We used HTML to add headings, paragraphs, images, lists, and links. We also used CSS in order to make the appearance more colorful and catch the attention the others, it would be boring if there was no detail or creatvitiy added into it. For example when using CSS, we customized it by using different fonts, background colors, borders, margins, padding,and postioning it to a more organized appearance, just like a movie we wanted things to seem welcoming.

relfection

One challenge I faced while creating this project was figuring out how to position and center certain elements, especially images or having to align the lists next to my words so that it wouldn't look odd when having everything be all over the place. I also had trouble trying to fix the colors of my text, they wouldn't appear the way I wanted it to and I would have to go back and make changes until I was able to figure out what mistake I was making. I had to adjust my CSS selectors and try different solutions to get the website to look the way we wanted it to look.

One thing I learned from this project was how important it is to organize HTML and CSS properly. I think for next time I should use comments in order to keep things organized and not just squish everything together, it makes things more complicated when I look back to it. I also learned that small changes to margins, padding, colors, and positioning can make a big difference in how a webpage looks. Even when I struggle with certain parts, I became more comfortable and confident when coding, it helps me improve the way I solve my problems and even for the future.

For my next steps, I would like to improve the appearance of my movie webpage by adjusting some of the spacing and positioning. One thing I want to accomplish went going to the next steps is going beyond coding, I want to be able to try out the more advanced things when it comes to coding, it helps expand my imagination with what I want my projects to look like. I want to be more detailed with the movie homepage and other parts, this helps bring more interest and excitement when looking at projects that have all sorts of different types of code. I want visitors to notice the creatvitiy added to it and hope to add new features to this project that could have been made.
